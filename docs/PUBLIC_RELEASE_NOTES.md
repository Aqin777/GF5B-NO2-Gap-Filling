# Public release notes

## Included

- English research overview and methods documentation.
- One aggregate figure reconstructed from verified early baseline metrics.
- One conceptual figure explaining the spatial-density weighting method.

## Intentionally excluded

- GF-5B source products and derived pixel-level tables.
- Ground-monitor observations, identifiers, and coordinates.
- Meteorological, population, elevation, land-cover, and other restricted inputs.
- Source code, including inherited or collaborator-authored code with unconfirmed redistribution rights.
- Models, checkpoints, prediction tables, caches, logs, archives, and intermediate products.
- Local or server paths, hostnames, usernames, environment files, credentials, tokens, cookies, and private contact details.
- Maps derived from restricted records and unpublished weighted-experiment result tables.

## Interpretation guardrail

The public R² = 0.7765 value is the early unweighted LightGBM random-cross-validation baseline. It is not a spatially weighted result. Spatial-density reweighting is implemented in later experimental scripts and remains under evaluation.

## Licensing status

No open-source or open-data license is included because ownership and redistribution permissions for the underlying research materials have not yet been confirmed. Absence of a license means no permission is granted for reuse by default.
